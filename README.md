# ✉️ MailCraft AI
### An Intelligent Multi-Agent Email Generation System

MailCraft AI is a Generative AI-powered email drafting application that helps users create personalized, context-aware and professional emails through a simple web interface.

Built using **Python, CrewAI, Streamlit and OpenRouter**, the application uses a collaborative multi-agent workflow to understand user requirements and generate relevant email drafts.

Users can select the type of email they want to write, describe the context, choose a preferred tone, provide recipient information and generate an email without needing to write it manually.

---

## 🚀 Key Features

- **Interactive Web Interface:** Simple and accessible interface developed using Streamlit.
- **Multiple Email Categories:** Generate follow-up, cold outreach, job application, apology, thank-you, meeting request, business proposal, complaint, resignation and leave request emails.
- **Context-Aware Generation:** Uses the user's description and additional details to generate relevant content.
- **Tone Customization:** Supports professional, formal, friendly, persuasive, apologetic and other communication styles.
- **Multi-Agent Collaboration:** Two specialized AI agents work sequentially to analyze requirements and generate the final email.
- **OpenRouter Integration:** Uses OpenRouter's free-model routing option instead of requiring OpenAI API credits.
- **Email Editing:** Allows users to review and modify generated drafts.
- **Download Functionality:** Download generated emails as text files.
- **Placeholder Handling:** Uses placeholders for missing information instead of inventing factual details.

---

## 🧠 How It Works

MailCraft AI follows a sequential multi-agent architecture using CrewAI.

### Agent 1: Email Context Analyst

**Role:** Email Context Analyst

Responsibilities:
- Understand the user's email requirements.
- Identify the purpose of the email.
- Analyze the recipient and communication context.
- Extract important information.
- Identify the appropriate email structure.
- Determine the suitable greeting, closing and call to action.

**Output:** A structured email writing brief.

### Agent 2: Professional Email Writer

**Role:** Professional Email Writer

Responsibilities:
- Receive the analysis generated by Agent 1.
- Draft an email based on the user's requirements.
- Maintain the selected communication tone.
- Include relevant information and a suitable subject line.
- Avoid introducing unsupported names, dates, links or other factual details.
- Produce a concise and readable email.

**Output:** A complete email draft ready for user review.

### Workflow Architecture

```text
             USER
               |
               v
       Streamlit Web UI
               |
               v
       User Requirements
               |
               v
    CrewAI Sequential Workflow
               |
               v
     Agent 1: Context Analyst
               |
               v
       Structured Email Brief
               |
               v
     Agent 2: Email Writer
               |
               v
       OpenRouter LLM
               |
               v
       Generated Email
               |
               v
       Streamlit Output
               |
          +----+----+
          |         |
          v         v
        Edit     Download
```

## ⚙️ Installation and Setup

### Prerequisites

Before running the application, make sure you have:

- Python 3.11 installed.
- Git installed.
- Visual Studio Code or another Python editor.
- An OpenRouter account and API key.

### Step 1: Clone the Repository

```bash
git clone https://github.com/harshitajain08/Auto-email-generation.git

cd Auto-email-generation
```

### Step 2: Navigate to the Application

```bash
cd agents/gen-ai
```

### Step 3: Create a Virtual Environment

Python 3.11 is recommended for compatibility with the project's CrewAI dependencies.

```bash
python3.11 -m venv .venv
```

Activate the environment:

**macOS / Linux**

```bash
source .venv/bin/activate
```

**Windows**

```bash
.venv\Scripts\activate
```

### Step 4: Install Dependencies

Upgrade pip:

```bash
python -m pip install --upgrade pip
```

Install the project dependencies:

```bash
python -m pip install -r requirements.txt
```

### Step 5: Configure the API Key

Create a local `.env` file using the example template:

```bash
cp .env.example .env
```

Open `.env` and add your OpenRouter API key:

```env
OPENROUTER_API_KEY=your_openrouter_api_key
```

Get your API key from:

https://openrouter.ai/settings/keys

**Security:** Never share your API key or upload your `.env` file to GitHub.

## ▶️ Running the Application

MailCraft AI supports two ways of running the email generation system.

### Option 1: Web Application (Recommended)

Start the Streamlit application:

```bash
python -m streamlit run app.py
```

Open the local application in your browser:

http://localhost:8501

Users can interact with the application through the web interface without entering command-line arguments.

### Option 2: Command-Line Interface

The email generation system can also be executed directly through Python.

Run:

```bash
python agent.py
```

You can provide custom requirements:

```bash
python agent.py \
  --context "Apologize for the delayed delivery of the project" \
  --tone "apologetic but confident" \
  --recipient "the client project manager"
```

Additional supported arguments:

| Argument | Description |
|---|---|
| `--context` | Describes the purpose and situation of the email. |
| `--tone` | Specifies the preferred writing tone. |
| `--recipient` | Identifies the intended recipient. |
| `--email-type` | Specifies the category of email. |
| `--details` | Provides additional information. |
| `--cta` | Specifies the desired call to action. |

## 🛡️ Reliability and Output Handling

MailCraft AI uses prompt instructions to improve the reliability of generated emails.

The system is designed to:

- Avoid fabricating names, dates, meeting times and links.
- Use placeholders when necessary information is unavailable.
- Adapt the email structure to the selected category.
- Follow the user's preferred communication tone.
- Generate content based on the supplied context.

Generated emails should always be reviewed by the user before being sent.

## 🔍 Troubleshooting

### 1. `ModuleNotFoundError: No module named 'crewai'`

Make sure the project's virtual environment is activated.

```bash
source .venv/bin/activate
```

Then install the dependencies:

```bash
python -m pip install -r requirements.txt
```

### 2. `ModuleNotFoundError: No module named 'streamlit'`

Install Streamlit:

```bash
python -m pip install streamlit
```

### 3. OpenRouter API Key Error

Check that:

- The `.env` file exists in the `agents/gen-ai/` directory.
- The variable is named `OPENROUTER_API_KEY`.
- The API key is valid.
- Your selected free model is available.

### 4. Streamlit Cannot Find CrewAI

Launch Streamlit through the active Python environment:

```bash
python -m streamlit run app.py
```

### 5. Python Version Compatibility

Use Python 3.11 and create a fresh virtual environment if dependency installation fails.
